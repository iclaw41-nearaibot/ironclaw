# Blockchain Agent Marketplace Skill

## Virtuals Protocol (Base Blockchain)
- Platform: app.virtuals.io
- Network: Base (Coinbase Layer 2, cheap and fast)
- Launch fee: 100 VIRTUAL tokens
- Earnings: inference fees paid in VIRTUAL tokens — more users = more earnings
- Best for: entertainment, gaming, and general-purpose agents
- Strategy: build audience first, then launch to maximise inference fee earnings

## Coinbase AgentKit
- Docs: docs.cdp.coinbase.com/agent-kit/welcome
- GitHub: github.com/coinbase/agentkit
- Gives IronClaw its own crypto wallet on Base/EVM chains
- Can: hold funds, send payments, trade tokens, earn yield, swap tokens
- Framework-agnostic — works with any LLM
- Use for: giving IronClaw financial autonomy to pay for its own tools/APIs

## Fetch.ai Agentverse
- Platform: agentverse.ai
- Token: ASI (formerly FET)
- Registration: via Almanac contract, renew every 48 hours
- Earnings: agents earn ASI tokens when users consume their services
- Best for: data services, compute services, API monetisation

## Bittensor Subnets (TAO)
- Decentralised ML marketplace
- Miners compete to provide best model outputs
- Validators score and rank miners
- Top AI crypto by market cap
- High barrier to entry but high earning potential

## Priority Order for Simon
1. **NEAR AI Market** — easiest, IronClaw is native NEAR AI product
2. **Virtuals Protocol** — after building audience, good passive income
3. **Coinbase AgentKit** — give IronClaw its own wallet for financial autonomy
4. **Fetch.ai** — later, for data/compute services

## IronClaw Wallet Setup
- NEAR wallet: wallet.near.org (for NEAR AI market)
- Base wallet: use Coinbase AgentKit CDP wallet (for Virtuals, Base transactions)
- Keep separate wallets for each chain
- Never store large amounts in hot wallets
